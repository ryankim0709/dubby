# Media

Put the scene clips you want to dub here (`.mp4`, `.mov`, or `.m4v`). Every clip in this folder is bundled into the app at build time and appears on the Discover tab, titled from its file name (`anakin-confronts-obi-wan.mp4` becomes "Anakin Confronts Obi Wan").

The clips themselves are ignored by git, so copyrighted footage never lands in the repository. Each machine supplies its own clips. Release builds must use original or properly licensed scenes.
